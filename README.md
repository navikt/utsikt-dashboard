# Dashbord om beregninger fra Oppdragssystemet

Applikasjonen blir ikke lenger deployet, da koden ikke er forvaltet aktivt for øyeblikket. Velger derfor å arkivere dette repoet, som er reversibelt dersom vi lager et nytt streamlit-dashbord.

# Kjør appen lokalt
```
cd app
streamlit run main.py
```
Obs! Working directory needs to be **/app** directory.
